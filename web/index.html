How it works

The solver works backward from k = N to k = 0.

At each step, it minimizes the running cost plus the interpolated next-step value function across admissible controls.

After the value table is computed, a forward rollout starts from the initial state and applies the optimal policy.

DSL quick guide

  • Wrap each problem inside problem <Name> ... end_problem.
  • Use # or // for comments.
  • Currently supports 1 or 2 state variables and exactly 1 control variable.
  • Supported operators: +, -, *, /, unary -, right-associative ^, and parentheses.
